Depot

One desktop window for every package manager: what is installed, what has updates, and what happened.

Depot is a desktop app for macOS and Windows that lists every package from every package manager in one place, groups pending updates by source, searches all sources at once, and keeps a history with a revert where the manager allows one.

It never changes anything except by running the package manager's own command, and each command appears in its log exactly as it was run. It is in preview with a small group of testers. Made with Claude.
